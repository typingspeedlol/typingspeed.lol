# typingspeed.lol

Static site, no build step. Upload the whole folder to the web root of typingspeed.lol.

Files
- index.html: the typing test (single file, all CSS and JS inline)
- about.html, privacy.html, terms.html, contact.html: policy and info pages
- robots.txt, sitemap.xml: crawler files (submit sitemap.xml in Search Console)
- favicon.svg, favicon.ico, apple-touch-icon.png, favicon-*.png: icons
- logo-mark.svg, logo-lockup.svg: logos

Add your own ads.txt at the root (AdSense gives you the line).
